# Residência - Trilhas em Tecnologias: IA Generativa & RAG

## 📚 Aulas

- [Aula 01 - Introdução à IA](./AULA_01/README.md)  
  Configuração do ambiente e primeira interação com um LLM via API.

- [Aula 02 - Extração de Metadados com Structured Outputs](./AULA_02/README.md)

## Tecnologias gerais

- Python
- GroqCloud API (compatível com o SDK da OpenAI)
- python-dotenv
- Virtual Environment (`venv`)

---

## Segurança

Chaves de API são armazenadas localmente em arquivos `.env`, que **não são versionados** (ver `.gitignore`). Cada pasta de aula contém instruções específicas de configuração.
